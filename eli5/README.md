# eli5 プラグイン

トピックを渡すと、「その分野を知らない大人」向けの図解HTMLを作り、Artifactとして発行するスキル。専門用語を避け、比喩だけで終わらせず必ず実物の仕組み・数字・対比まで書く。

**社内利用専用。** 社外への再配布・公開リポジトリへの転載はしない。

## 何をするか

1. トピックを受け取り、読み手が実際に抱く問いの順で骨子を作る
2. 骨子を図解HTMLに組む(見出し・本文・アイコン)
3. Claude Code の Artifact として発行する(あわせてローカルにもHTMLを保存する)

案件・自社事業の分析やリサーチ結果が入力のときは、ビルド前に同梱の `cherry-pick-auditor` エージェント(`eli5:cherry-pick-auditor`)が骨子を監査し、証拠の選び方に偏りがないかを検査する。

## 3つの深さ(`--depth`)

| 段 | 指定 | 目安の分量 | 使う場面 |
|:--|:--|:--|:--|
| 軽い | `--depth=light` | 2,500〜3,500字 | 用語1つ・身近な概念 |
| 標準 | 指定なし(既定) | 6,000〜9,000字 | 仕組みがあるもの |
| 深い | `--depth=deep` | 10,000〜15,000字 | 多層・トレードオフがあるもの |

## 2つのアイコン源(`--icons`)

読み手が「自分自身か社内」か「社外」かで自動判定する(`--icons=koboyo` / `--icons=material` で上書き可能)。

| アイコン源 | 使う場面 | 件数 |
|:--|:--|--:|
| Koboyo(手書き風) | 学習・入門・社内共有 | 20,129種 |
| Material Symbols Outlined | クライアント・役員・投資家向け | 4,226種 |

アイコン名は必ず実在確認(`verify`)を通してから使う。捏造した名前は使わない。

## 機密の扱い

トピックや参照元にクライアント名・案件名・未公開の財務数値・社外秘情報が含まれる場合、**発行前に必ず確認が入る**。自動で「問題なし」と判断して外部発行することはない。同時に、自動で発行を止めることもない。判断は必ず利用者に委ねる。

## 使い方

```
/eli5 ベクトル検索の仕組み
/eli5 --depth=deep --icons=material 事業計画の作り方
```

詳細な手順は `skills/eli5/SKILL.md` を参照。
